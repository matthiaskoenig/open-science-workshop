# Open Science Workshop
This repository contains the information about the **Reproducible & Open Workflows** Workshop.

## Installation
### Clone repository
Use a git client such as [GitHub Desktop](https://desktop.github.com/download/) to get the latest code. 
Select the repository https://github.com/matthiaskoenig/open-science-workshop.git and clone it.  

Via the command line it can be cloned via
```bash
git clone https://github.com/matthiaskoenig/open-science-workshop.git
cd open-science-workshop
```
The repository is private so you have to request access to the repository first.

### Create environment with uv
Installation with uv (https://docs.astral.sh/uv/getting-started/installation/)
```bash
uv sync
```
